# 一、简介​

欢迎使用炎核通用多内核开发引擎（General Multi-kernel Development Engine）——GMDE-PySDK。粤港澳大湾区（广东）国创中心（以下简称 “国创中心”）拥有 GMDE-PySDK 完全自主可控的产权。​

GMDE-PySDK 是一款为 CAD/CAE领域打造的高效开发工具，集成了丰富的功能模块。其中，PyCAEPre 应用软件开源源码作为 GMDE-PySDK 的重要组成部分，采用木兰宽松许可开源，方便开发者自由使用、修改和分发；而 SDK 开发工具包则提供个人免费非商业许可（商业许可证需向国创中心单独申请），为个人非商业场景下的开发工作提供支持。​

# 二、依赖环境​

1.编程语言环境：需安装 Python 3.8 及以上版本。建议使用官方推荐的 Python 发行版，以确保与 GMDE-PySDK 的兼容性，减少因版本问题导致的开发障碍。​

2.授权凭证获取：需从国创中心提供的炎核官网获取相关授权凭证。其中，针对 SDK 开发工具包的非商业使用，需按流程申请授权凭证；PyCAEPre 开源源码可直接获取使用，无需额外授权。​

# 三、获取授权​

**（一）获取相关授权凭证（针对 SDK 开发工具包）​**

在使用 SDK 开发工具包前，个人用户需按以下步骤操作：
​
访问国创中心旗下的炎核官方网站，找到 GMDE-PySDK 非商业使用注册入口。
​
按照网站指引完成注册流程，准确填写个人信息、使用场景及使用机器（通过下再网站的工具识别）等相关内容，提交非商业使用申请。
​
申请通过后，将获取相应的授权凭证（绑定机器码信息的SDK使用license）。这些凭证是使用 SDK 开发工具包的重要依据，需严格保管在安全的位置，避免泄露给无关第三方，以防被非法使用。​

**（二）许可验证配置​**

用户获取正确配置授权信息后，将授权凭证准确导入到开发环境中。使用过程中，确保授权信息处于有效状态，若授权即将过期，需及时通过官方渠道进行续期申请。​

# 四、获取安装​

**（一）执行文件安装（推荐）：**

下载对应系统的执行文件，双击启动向导，同意许可协议后，在许可配置页填写获取的机器码绑定信息和 SDK 使用 license，完成验证。接着选择安装路径，点击安装，程序自动完成适配版本安装，最后点 “完成” 即可。​

**（二）源码包安装：**

下载源码包并解压，打开终端进入解压目录，执行 python setup.py install。安装过程中按提示填写机器码绑定信息和 SDK 使用 license 完成验证，系统自动安装依赖，显示成功后即可导入使用。

# 五、许可信息​

PyCAEPre 应用软件开源源码的许可证类型：木兰宽松许可证（开源许可证）​

SDK 开发工具包的许可证类型：个人免费非商业许可（商业许可证需向国创中心单独申请）

详细许可条款请参阅《炎核多内核CAD&CAE开发平台社区版软件许可协议》文件。​
