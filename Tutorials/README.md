# Tutorials 

本目录为 **实战案例代码库**
课程知识库主页：[https://opencax.cn/gmde/knowledge/index]

## 📖 简介

整套案例按照课程学习顺序编排，你完整克隆或下载本仓库后，案例代码、配套几何素材全部就位。进入对应案例目录即可直接运行调试，对照线上文档同步练习，快速上手进行二次开发。

## ⚙️ 运行环境要求

### 基础环境

1. **Python 运行版本**
推荐 Python 3.8 ~ Python 3.12；不建议使用 Python 3.13 及以上未充分验证版本。



### ⚠️ 常见环境注意事项

1. 路径尽量不要使用中文、空格目录，避免几何文件读取、内核运行出现未知异常。


## ▶️ 使用方法

1. 将整个仓库完整克隆 / 下载到本地
2. 完成境配置
3. 进入目标案例文件夹，执行启动脚本
4. 打开案例内 `readme.md`，跳转至对应课程页面对照学习

## 📌 版本兼容说明

案例代码与主仓库 SDK 同步维护。
如内核接口发生变更，案例脚本会同步更新。若运行报错，请优先确认本地 SDK、PyCAEPre 代码为仓库最新版本。

## 💡 学习建议

1. 按照章节顺序循序渐进练习；
2. 修改脚本参数反复调试，观察几何、网格结果变化；
3. 线上课程留言区可交流案例运行遇到的问题；
4. 欢迎提交 PR 贡献新练习案例。
