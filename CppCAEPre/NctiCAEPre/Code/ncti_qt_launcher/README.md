# ncti_qt_launcher

## 环境配置

### Qt 版本
Qt5.14.2 msvc2017_64

### C++ 标准
C++20

工程配置： `64位 | Unicode | RelWithDebInfo`

### 第三方库
- SARibbon
    - QWindowKit
        - qmsetup
